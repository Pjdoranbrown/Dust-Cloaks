# Dust Cloaks

A bullet heaven / action RPG adaptation of the Dust Cloaks tabletop game.

## Play

Open `index.html` in a web browser. That's it — no install needed.

Online: https://pjdoranbrown.github.io/Dust-Cloaks/

## Files

- `index.html` — the game: layout, styles and all game code.
- `assets/*.js` — built-in painted images (portraits, Rank'n card art), stored as data so the game can read their pixels even when opened straight from disk. `index.html` loads them before the game code.
