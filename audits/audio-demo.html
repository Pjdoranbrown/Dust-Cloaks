Dust Cloaks - audio listening demo

Standalone page: no game code. Everything is made live with Web Audio. Use headphones or decent speakers; the problem frequencies are around 800-2000 Hz. Click Start first (browsers need a click before audio).

1. Timbre: current pipe vs proposed lute (same notes)

Same phrase (Embers, first two bars, A minor). "Pipe" is the game's current melody voice re-created from the code (sine + octave triangle, 5 Hz vibrato, breath chiff, no reverb). "Lute" is a Karplus-Strong string, filtered, with a touch of room.

2. The theme: Town → Contract, one tune that builds

One looping 8-bar melody. Hit a preset, or switch layers by hand while it plays. The tempo changes smoothly over about two bars, like Humanity's time speed-up.
